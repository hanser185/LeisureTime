## 阅读顺序建议

1. 先读 **01-PRD** 确认「解决什么问题、为谁解决、不解决什么」。
2. 再看 **02-技术选型** 确认技术栈（待你拍板）。
3. 然后 **03/04** 理解结构与核心逻辑。
4. **05/06** 看界面与代码骨架。
5. **07/08** 看交付与质量保障。

## ✅ 已确认决策（V1 范围基线）

| 决策点 | 结论 |
|--------|------|
| 技术栈 | **Tauri 2 + Vue 3 + TS + Rust 核心**（已定，见 02 文档） |
| 提醒方式 | 设置提供 **Toast / 弹窗 / 全屏** 三种可切换，**默认 Toast** |
| 全屏遮罩 | **首版暂缓**：先实现 Toast + 弹窗，全屏留作后续；设置项保留但首版未实现 |
| 工作时段限制 | **默认关闭**（全天提醒），设置内可开启工作日 9–18 |

> 结论已同步至 02 / 05 文档与项目记忆。下一步：进入编码（src-tauri 核心 + Vue 前端）。
