# 12 · 端到端验证清单（真机）

> 用途：在 Windows 真机（GUI + WebView2）上逐项点检，确认功能与已修复的 6 个低级 bug 在真实环境生效。
> 前置：已用最新代码构建绿色包（见 `doc/10` 出包步骤）。沙箱无法渲染 WebView2 GUI，故必须真机验证。
> 提示：为快速验证与"计时/提醒"相关的项，可在「设置」里把**工作阈值**临时调小（如 5 分钟）、**喝水间隔**调小（如 5 分钟），验证完再调回。

---

## A. 基础启动与退出

- [ ] 解压绿色 zip，双击 `rest-reminder.exe` 能启动（非安装依赖）。
- [ ] 若双击无反应：确认目标机已装 WebView2 Runtime（Evergreen）。
- [ ] 首次启动展示隐私引导，确认后进入主界面。
- [ ] 关闭主窗口只是最小化到托盘，程序仍在运行（非退出）。
- [ ] 右键托盘 → 「退出」才真正结束进程（任务管理器确认进程消失）。
- [ ] 左键托盘图标：打开 / 聚焦主窗口。
- [ ] 断网状态下功能正常（零网络外联，隐私红线）。

## B. 休息提醒（含 Bug① 循环提醒、Bug④ 休息次数）

- [ ] 静置/连续工作达工作阈值后弹出休息提醒；「跳过 / 稍后」按钮可正常关闭弹窗。
- [ ] **Bug① 验证**：工作阈值设为 5 分，连续工作 12+ 分（不点跳过），应收到 **≥2 次**休息提醒（此前只会弹一次）。
- [ ] **Bug④ 验证**：多次触发休息提醒后，Dashboard 的「休息次数」**大于 0** 且随提醒累加（此前恒为 0）。
- [ ] 休息弹窗 20 秒无操作自动关闭。

## C. 喝水提醒（含 Bug⑤ 下溢/死事件、Bug⑥ 自动关闭）

- [ ] 喝水提醒按间隔触发；与休息提醒冲突时错开排队（不同时弹两个）。
- [ ] **Bug⑥ 验证**：打开喝水弹窗后不操作，20 秒后**自动关闭**（此前不会自动关，always-on-top 可能卡死）。
- [ ] 「喝了」记录喝水并关闭；「稍后」推迟下次提醒并关闭。
- [ ] **Bug⑤ 验证**：长时间运行（含系统时间跨午夜/回拨）不崩溃、不 panic（saturating 防 u64 下溢）。

## D. 暂停行为（Bug② 暂停误判休息）

- [ ] 工作到接近阈值（如阈值 5 分，工作约 4 分）→ 右键托盘「暂停」→ 暂停 5 分 → 「恢复」。
- [ ] 恢复后**不会**立即被误判为"休息"并切到 Resting（此前暂停时长被算作无活动，恢复瞬间跨阈值即误切）。
- [ ] 恢复后统计（工作/休息时长）不被暂停时长污染。

## E. 清空今日（Bug③ 旧片段复活）

- [ ] 先工作一段时间产生今日片段/统计 → 设置里「清空今日数据」→ 确认清空。
- [ ] 清空后继续工作，**今日数据不应出现清空前旧片段被"复活"写入**的情况（此前清空只清 daily、不复位在途片段，下次归档会把旧片段写回空日）。
- [ ] 清空后 Dashboard 当前状态/累计归零正常。

## F. 数据与托盘

- [ ] 数据按日落盘于 `%LOCALAPPDATA%\rest-reminder`，删除该目录可清空历史。
- [ ] 托盘菜单项齐全：暂停/恢复、打开设置、退出。
- [ ] 设置各项（阈值/休息判定/提醒方式/喝水/工作时段/自启/主题）保存后生效、重启后保持。

## 通过标准

A、B、C、D、E、F 全部勾选 → 质量闭环完成，可发布到 GitHub Releases。
任一项失败 → 记录现象与复现步骤，回到对应源码（state.rs / scheduler.rs / commands.rs / 前端组件）定位。
