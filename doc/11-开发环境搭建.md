# 11 · 开发环境搭建

> 面向想从源码构建或参与开发的贡献者。普通用户请直接下载绿色版（见 README「快速开始」，出包流程见 [doc/10](./10-出包与发布（绿色便携版）.md)），**无需**搭建本环境。

## 1. 前置依赖（Windows）

| 依赖 | 用途 | 安装 |
|------|------|------|
| Rust（stable） | Rust 核心编译 | [rustup.rs](https://rustup.rs/) |
| WebView2 Runtime | Tauri 2 依赖的系统 WebView（Win10/11 通常已预装） | [官方下载](https://developer.microsoft.com/microsoft-edge/webview2/) |
| Visual Studio Build Tools | C/C++ 链接器（需勾选「使用 C++ 的桌面开发」工作负载） | [官方下载](https://visualstudio.microsoft.com/visual-cpp-build-tools/) |
| Node.js 18+ | 前端依赖与 Tauri CLI | [nodejs.org](https://nodejs.org/) |

> 本机若已装齐上述工具，跳过对应步骤即可。

## 2. 安装与运行（开发模式）

```bash
npm install                 # 安装前端依赖
npm run tauri dev           # 启动开发：前端热更新 + Rust 重新编译
```

## 3. 生产构建

```bash
npm run tauri build         # 产物位于 src-tauri/target/release/bundle/
```

详细的打包形态、签名与发布流程见 [doc/07-打包与安装部署](./07-打包与安装部署.md)；绿色便携版出包步骤见 [doc/10-出包与发布（绿色便携版）](./10-出包与发布（绿色便携版）.md)。

## 4. 关于代码签名（v1 不签名）

v1 暂未做代码签名：首次运行可能看到 Windows SmartScreen 警告，点「仍要运行」即可。后续如需消除警告，可购买 OV/EV 代码签名证书并用 `signtool` 对 `rest-reminder.exe` 签名，命令见 doc/07 §3。

## 5. 构建验证

- 前端：`npm run type-check`（`vue-tsc --noEmit`）应通过。
- Rust：`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test`（在 `src-tauri/` 内）应全绿。
- 生产打包在 Windows + Rust 工具链下执行 `npm run tauri build`；CI 仅做检查（fmt/clippy/test + 前端 type-check），配置见 `.github/`。
