# 02 · 技术选型说明

> 需求 §3 要求：在选项 A（Tauri）与 选项 B（.NET）中选一，并说明理由。

---

## 1. 约束回顾

- **平台**：仅 Windows。
- **轻量**：安装包 < 20 MB，常驻内存 < 100 MB。
- **隐私**：全局键鼠监听，不记录内容、不上传。
- **体验**：冷启动 < 2 秒，长时运行稳定。

---

## 2. 选项对比

| 维度 | 选项 A：Tauri 2 + Vue 3 + TS + Rust | 选项 B：.NET 8（WPF / WinUI 3） |
|------|--------------------------------------|----------------------------------|
| 安装体积 | **极小**（Rust 二进制 ~2–5 MB + 系统 WebView2，无需打包运行时） | 自包含（self-contained）易超 100 MB；依赖系统 .NET 则需用户先装运行时 |
| 内存占用 | 低（Rust 核心 + 单 WebView 进程） | 中等（WPF/WinUI + CLR 开销） |
| 全局键鼠监听 | `rdev` crate（仅事件、不记录内容，隐私友好） | `SetWindowsHookEx` / `globalmousekeyhook` 库，原生支持好 |
| UI 开发效率 | Vue 3 + Vite，组件化、热更新快 | XAML 声明式，原生控件美观但迭代慢 |
| 托盘/通知 | Tauri v2 内置 tray + notification 插件 | 原生 `NotifyIcon` / `ToastNotification` |
| 跨平台潜力 | 有（虽本次不做） | 弱（绑定 Windows） |
| 对标项目 | **Catrace 即用 Tauri** | 无直接对标 |
| 分发签名 | 标准 exe 签名 | 标准 exe 签名 |
| 学习/维护成本 | Rust 有一定门槛 | C# 团队更易招/维护 |

---

## 3. 推荐方案

### ✅ 选项 A：Tauri 2 + Vue 3 + TypeScript + Rust 核心

**理由：**

1. **体积与内存天然满足硬指标**：Tauri 复用系统 WebView2，不内嵌浏览器内核，安装包轻松 < 20 MB，常驻内存 < 100 MB 可达。
2. **隐私实现最干净**：`rdev` 库只回调「事件发生」与「键码/按键类型」，天然拿不到文本内容，从机制上杜绝「记录按键」的风险，契合 §4.4 / §8 的隐私红线。
3. **与对标项目一致**：Catrace 用 Tauri，思路可直接借鉴（状态检测、后台常驻、托盘），但不复制其 UI/实现。
4. **前端体验好**：Vue 3 + Pinia 做 Dashboard / 设置 / 提醒组件，迭代快、对非技术用户友好。
5. **Rust 核心稳定**：后台计时、调度、存储用 Rust 编写，无 GC、长时运行不易内存泄漏。

**可接受的成本**：需少量 Rust 知识（活动监听、托盘、存储），但代码量小，文档 §6 已给骨架。

---

## 4. 备选说明（若你坚持 .NET）

若团队更熟悉 C# 或需要极致原生体验，可选 **.NET 8 + WPF**：
- 用 `globalmousekeyhook` / `MouseKeyHook` NuGet 包监听全局输入。
- 托盘用 `System.Windows.Forms.NotifyIcon`（WPF 可承载）。
- 体积控制靠「依赖系统已装 .NET 运行时」+ 单文件发布（`dotnet publish -p:PublishSingleFile=true`），但仍可能 > 20 MB，需压缩/裁剪。
- 启动速度略慢于 Tauri（CLR 启动），但 < 2 秒在 SSD 上可达。

> 结论：**默认推荐 Tauri 方案**；除非你有强 C# 团队或需深度 Windows 原生集成，才选 .NET。

---

## 5. 依赖清单（Tauri 方案）

- 框架：Tauri 2.x
- 前端：Vue 3 + Vite + TypeScript + Pinia
- Rust crates：`rdev`（输入监听）、`serde` / `serde_json`（存储）、`tauri`（核心）、`tauri-plugin-notification`（Toast）
- 打包：`tauri-build` + NSIS 或 WiX（MSI）

---

## 6. 决策结论（已确认）

- ✅ 采用 **Tauri 2 + Vue 3 + TypeScript + Rust 核心** 方案。
- ✅ 前端选用 **Vue 3**（轻量、与 Catrace 一致）。
