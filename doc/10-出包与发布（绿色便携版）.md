# 10 · 出包与发布（绿色便携版）

> 关联：[`doc/07-打包与安装部署`](./07-打包与安装部署.md)。v1 定位为**绿色便携版**（解压即用、不签名、参考 TrafficMonitor）。

## 1. 为什么不打安装包

v1 决策（doc/07）：不做 NSIS/MSI 安装器、不代码签名。用户下载后**解压即运行**，不产生注册表项、不写入 Program Files。

实现要点：`src-tauri/tauri.conf.json` 中 `bundle.active` 设为 `false`。此配置下 `tauri build` 只编译出裸二进制 `rest-reminder.exe`，**不会**去下载 NSIS/wix 生成安装包。

> Tauri 2 在编译期已通过 `tauri::generate_context!` 把前端 `dist/` 与图标**内嵌进 exe**，因此单文件即可独立运行，仅需目标机器装有系统组件 **Microsoft Edge WebView2 Runtime**（Win10/11 通常已自带）。

## 2. 出包步骤（每次发版）

在本机 Windows（已装 Rust + VS Build Tools + WebView2 + Node 18+）执行：

```powershell
# 1) 拉最新代码并安装前端依赖
npm install

# 2) 构建前端 + 编译 Rust 发布二进制（仅 exe，无安装包）
npm run tauri build
#   产物：src-tauri/target/release/rest-reminder.exe

# 3) 打成绿色 zip（含使用说明）
powershell -ExecutionPolicy Bypass -File scripts/package-green.ps1
#   产物：src-tauri/target/release/bundle/portable/休息提醒助手_vX.Y.Z_portable.zip
```

## 3. 发布包内容

```
休息提醒助手_v0.1.0_portable.zip
├─ rest-reminder.exe     # 主程序（自包含前端，仅需系统 WebView2）
└─ 使用说明.txt          # 解压即用说明、WebView2 依赖提示、数据目录、退出方式
```

## 4. 发布前验证清单（出包后必做）

- [ ] 在**纯净环境/另一台机器**解压，双击 `rest-reminder.exe` 能启动（验证非安装依赖）。
- [ ] 若双击无反应：确认目标机已装 WebView2 Runtime（Evergreen）。
- [ ] 主窗口弹出，右上角仅「暂停/恢复」按钮，最小化/关闭由原生标题栏提供。
- [ ] 静置超过工作阈值后弹出休息提醒；「跳过 / 稍后」按钮可正常关闭弹窗。
- [ ] 关闭窗口后程序仍在托盘运行（非退出）；右键托盘可退出。
- [ ] 数据按日落盘于 `%LOCALAPPDATA%\rest-reminder`，删除该目录可清空历史。
- [ ] 断网状态下功能正常（零网络外联，隐私红线）。

## 5. 版本与发布

- 版本号同时维护在 `src-tauri/tauri.conf.json` 的 `version` 与前端 `package.json` 的 `version`，保持一致的语义化版本。
- 发布渠道：GitHub Releases 上传上述 portable zip（v1 不签名，发布说明中注明“未签名，自行决定是否信任”）。
- 后续若要提供 installer，再把 `bundle.active` 改回 `true` 并恢复 `targets`；v1 不做。

## 6. 注意事项

- `npm run tauri build` 在 `active:false` 下仍会走完整的 `cargo build --release`，耗时主要在 Rust 编译，属正常。
- 出包脚本输出位于 `target/release/bundle/portable/`，已被 `.gitignore`（`**/src-tauri/target/`）忽略，不会误提交。
- 不要提交 `target/` 任何产物；只提交源码、配置、脚本与文档。
