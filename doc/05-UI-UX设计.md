# 05 · UI/UX 设计

> 需求 §4。所有界面以「低打扰、非技术用户友好」为原则。

---

## 1. 主窗口（MainWindow）

单一窗口，内部分两个 Tab：**今日（Dashboard）** 与 **设置（Settings）**。窗口可关闭 → 仅最小化到托盘。

### 1.1 Dashboard（今日统计）

布局（自上而下）：

```
┌─────────────────────────────────────────┐
│  休息提醒助手                     [最小化] │
├─────────────────────────────────────────┤
│  Tab: [ 今日 ]  [ 设置 ]                  │
│                                           │
│  ● 当前状态：工作中（已连续 38 分钟）      │
│                                           │
│  ┌────────┐ ┌────────┐ ┌────────┐        │
│  │ 工作时长 │ │ 休息次数 │ │ 喝水次数 │        │
│  │  3h12m  │ │   2    │ │   3    │        │
│  └────────┘ └────────┘ └────────┘        │
│                                           │
│  今日时间轴：                             │
│  [工作 45m][休息 5m][工作 50m][休息 6m]…  │
│                                           │
│  喝水记录：09:15  10:30  11:40            │
└─────────────────────────────────────────┘
```

- 状态用颜色区分：工作中（蓝）、休息中（绿）、已暂停（灰）。
- 时间轴用彩色条带直观展示工作/休息节律。

### 1.2 Settings（设置）

表单字段（带默认值与 tooltip 说明）：

| 字段 | 控件 | 默认 |
|------|------|------|
| 工作时长阈值 | 数字输入（分钟） | 45 |
| 休息判定时长 | 数字输入（分钟） | 5 |
| 提醒方式 | 下拉：Toast / 弹窗 / 全屏（**默认 Toast**；全屏首版暂缓，选项保留但选中时回退弹窗） | Toast |
| 启用喝水提醒 | 开关 | 开 |
| 喝水间隔 | 数字输入（分钟） | 60 |
| 仅工作时段提醒 | 开关 + 起止时间 | 关 |
| 暂停检测 | 开关 | 关 |

底部固定 **隐私说明区块**（见 §4）。

## 2. 休息提醒界面

### 2.1 系统 Toast（默认）

- 右下角 Windows Toast，标题「该休息一下啦～」，正文显示已工作时长。
- 按钮：`稍后 5 分钟` / `稍后 10 分钟` / `跳过本次`。
- 点击按钮通过 Tauri 命令回传 Rust。

### 2.2 单窗口弹窗（备选）

- 居中或右下角无边框窗口，显示「休息 20 秒」倒计时环。
- 按钮：`跳过本次`（立即关闭）；倒计时归零自动关闭。
- 不阻塞其他窗口操作（置顶但可点穿或低优先级）。

### 2.3 全屏遮罩（可选，优先级最低）

> **决策：首版暂缓。** 设置项保留「全屏」选项，但 V1 选中时回退为弹窗；待 Toast + 弹窗打磨稳定后再实现。

- 半透明全屏窗口，中央大字「休息一下，看看远处」。
- 提供「结束休息」按钮关闭；默认停留至用户主动关闭或短时自动消失。

## 3. 喝水提醒卡片

- 独立小卡片（Toast 或右下角小窗），标题「该喝水啦 💧」。
- 按钮：`已喝水`（记录一次并关闭）、`稍后`（5 min 后再提醒）。
- 不强制，低打扰。

## 4. 隐私说明（设置页内）

> 我们以「隐私优先」设计本应用：
> - 本应用仅监听键盘/鼠标的**活动事件**（用于判断您是否在使用电脑），**不记录任何按键内容、不截屏、不录音**。
> - 所有数据（设置、工作时长、喝水记录）仅保存在您本机 `%APPDATA%` 目录，**不会上传到任何服务器**。
> - 您可以随时在设置中「清空今日数据」，或手动删除本地数据文件。

## 6. 前端组件示例（Vue 3 片段）

```vue
<!-- RestPopup.vue：休息弹窗（倒计时自动关闭） -->
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { invoke } from '@tauri-apps/api/core'

const remain = ref(20)            // 倒计时秒数
let timer: number

onMounted(() => {
  timer = window.setInterval(() => {
    remain.value -= 1
    if (remain.value <= 0) close(true)   // 自动关闭 = 接受休息
  }, 1000)
})

async function close(auto: boolean) {
  window.clearInterval(timer)
  if (!auto) await invoke('skip_rest')    // 用户手动跳过
  // 关闭窗口逻辑（Tauri window.close）
}
</script>

<template>
  <div class="popup">
    <h2>该休息一下啦 🌿</h2>
    <p>已连续工作一段时间，起来走走、看看远处吧。</p>
    <div class="count">{{ remain }} 秒后自动关闭</div>
    <button @click="close(false)">跳过本次</button>
  </div>
</template>
```

## 7. 设计原则小结

- **不打断**：默认 Toast，非全屏强制。
- **可跳过**：每次提醒都给出口。
- **可视化**：Dashboard 让「隐形时间」变可见，强化反馈。
- **可信赖**：隐私说明常驻，数据本地可查。
