# 07 · 打包与安装部署

> 需求 §6。目标：安装包 < 20 MB，**主打绿色版（解压即用，参考 TrafficMonitor）**，可选 NSIS/MSI 安装包；v1 不签名。

---

## 1. 构建流程

### 1.1 开发构建
```bash
npm install
npm run tauri dev      # 本地调试（前端热更新 + Rust 重新编译）
```

### 1.2 生产构建（生成安装包）
```bash
npm run tauri build
```
产物位于 `src-tauri/target/release/bundle/`：
- `nsis/` → `休息提醒助手_0.1.0_x64-setup.exe`（NSIS 安装包，可选）
- `msi/`  → `休息提醒助手_0.1.0_x64_en-US.msi`（MSI，可选，企业部署用）
- 绿色版 exe → `src-tauri/target/release/休息提醒助手.exe`（**主交付物**，直接拷贝即用，见第 2 节）

### 1.3 体积控制（确保 < 20 MB）
- Tauri 复用系统 WebView2，**不内嵌 Chromium**，天然小巧。
- 前端构建开启压缩：`vite.config.ts` 中 `build.minify = 'esbuild'`。
- 图标用 `.ico` 多分辨率单一文件，避免冗余资源。
- 不打包任何运行时（Rust 静态链接）。

---

## 2. 发布形态：绿色版为主，安装包为辅

参考 [TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor) 的发布方式：**优先提供"绿色版/便携版"压缩包，用户解压即可运行、无需安装**；NSIS/MSI 安装包作为可选补充。

### 2.1 绿色版（主交付物）
- 位置：`src-tauri/target/release/休息提醒助手.exe`（Tauri 构建后始终产出，与是否打安装包无关）。
- 依赖：仅需系统已装 **WebView2 Runtime**（Win10/11 绝大多数自带；缺失时首次运行会引导安装）。
- 打包：将 exe 单独压缩即可发布。
  ```powershell
  # 构建后一键打包绿色版（PowerShell）
  cd src-tauri/target/release
  Compress-Archive -Path "休息提醒助手.exe" -DestinationPath "休息提醒助手_green_x64.zip"
  ```
- 数据落盘：当前数据写在 `%LOCALAPPDATA%\rest-reminder\`（与 exe 位置无关），因此绿色版换机器/拷 U 盘时历史数据不会随身带走。若要做到"完全便携（配置随身）"，需把数据目录改为"exe 同目录"，见第 5 节。

### 2.2 安装包（可选）
| 类型 | 优点 | 适用 |
|------|------|------|
| NSIS | 体积小、向导可定制、支持静默安装 | 普通用户分发 |
| MSI  | 企业组策略部署友好 | 公司内网批量部署 |

> 建议：**v1 只发绿色版**；等需要"开始菜单/卸载入口/开机自启一键勾选"时再补 NSIS。

## 3. 代码签名（可选 · v1 不签名）

### 3.1 为什么需要签名
未签名 exe 在 Windows 上会被 **SmartScreen** 拦截，弹出"Windows 已保护你的电脑 / 无法识别的发布者"，用户需手动点"仍要运行"。签名的作用：
1. 证明文件确实由你发布、未被篡改；
2. 建立发布者信誉，逐步消除 SmartScreen 警告。

### 3.2 证书类型与选型
| 类型 | 验证内容 | 大致成本/年 | 消除 SmartScreen | 硬件 |
|------|---------|------------|------------------|------|
| OV（组织验证） | 公司/个人真实存在 | 约 ¥1000–3000 | 需累积信誉（发几个版本后警告减少） | 软证书，无 |
| EV（扩展验证） | 更严格审核 + 法律实体 | 约 ¥3000–6000+ | **立即消除**（首次即白名单） | 必须 USB 加密狗（HSM） |

### 3.3 本项目的决定
- **v1 不签名**：主打绿色版、自用/小范围测试，点"仍要运行"即可，省去每年数千元证书费。
- 仅当你要**公开发布给别人下载**时才考虑：先上 OV（便宜、软证书，攒信誉）；想一步到位用 EV（贵、需插 U 盾）。

### 3.4 签名命令（有了证书之后）
```bash
# Windows SDK 的 signtool，对绿色版 exe 签名（建议加 RFC3161 时间戳，证书过期仍有效）
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a ^
  /f mycert.pfx /p <密码> ^
  "休息提醒助手.exe"
```
- 可把签名接进 Tauri 的 `signCommand` 实现构建后自动签名；
- CI（GitHub Actions）中把证书与密码存为 Secret，构建后自动签名。

### 3.5 不签名的缓解手段
- 在下载页 / README 提供 **SHA256 校验值**，增强用户信任；
- 首次运行内置隐私引导说明，缓解疑虑；
- 持续分发累积下载量，SmartScreen 信誉会自然提升。

## 4. 自动更新（后续可选）

- Tauri 内置 `tauri-updater`（需签名更新包 + 更新服务器）。
- 首版可不做；后续用 GitHub Releases 作为更新源。

## 5. 数据位置与安装后行为

- 用户数据（设置、每日统计）写入 `%LOCALAPPDATA%\rest-reminder\`（settings.json + data/<日期>.json）。
- 绿色版与安装版共用同一数据目录，**换机器 / 拷 U 盘不会带走历史数据**。
- 若要做到"完全便携（配置随身、拷到哪用到哪）"，需把数据目录改为"exe 同目录下的 `data/`"——这是一项代码改动（`storage.rs` 中按"exe 旁是否存在 `data/` 目录"来切换路径），v1 暂不做，列为后续增强。
- 安装包（可选）安装时勾选「开机自启动」（**默认关**，设置内可开）；
- 卸载时清理程序，**保留用户数据**（或提供「同时删除我的数据」选项，默认不勾）。
