# 休息提醒助手（Rest Reminder）

后台守护你的工作节奏的 Windows 桌面应用。仅监听键盘/鼠标**活动事件**（不记录内容、不上传），按节奏提醒休息与喝水。

- 技术栈：**Tauri 2 + Vue 3 + TypeScript + Rust**
- 原生 Windows 桌面程序（非 Web 应用），体积小、内存低
- 数据全部存本地 `%LOCALAPPDATA%/rest-reminder/`，零网络外联

## 功能

- 工作状态检测：首次活动起算；连续工作达阈值（默认 60 分）提醒；连续无活动达休息阈值（默认 10 分）判为休息并开新片段
- 休息提醒：弹窗（首版全屏回退弹窗）；「稍后 5/10 分钟」重置计时、「跳过本次」本片段不再提醒；弹窗 20 秒自动关
- 喝水提醒：默认开，间隔 60 分，仅活跃时触发；与休息提醒冲突时错开排队
- 系统托盘常驻：暂停/恢复、打开设置、退出；关闭主窗口仅最小化到托盘
- 设置：阈值/休息判定/提醒方式/喝水/工作时段/自启/主题 + 清空今日数据 + 查看数据位置 + 恢复默认
- Dashboard：当前状态、累计工作/休息、休息次数、喝水次数、最长连续工作、下次喝水倒计时、今日时间轴、本周趋势、今日活动明细
- 隐私：不记内容、不上传；首次启动隐私引导 + 设置常驻说明

## 快速开始（绿色版）

1. 从发布页下载 `休息提醒助手_vX.Y.Z_portable.zip` 并解压。
2. 双击 `rest-reminder.exe` 启动（仅需目标机已装 **WebView2 Runtime**，Win10/11 通常自带）。
3. 首次启动会展示隐私引导，确认后即进入主界面。
4. 程序常驻系统托盘，交互方式：
   - **左键**托盘图标：打开 / 聚焦主窗口
   - **右键**托盘图标：暂停 / 恢复、打开设置、退出
5. 关闭主窗口只是**最小化到托盘**，不会退出；需右键托盘选「退出」才真正结束。

> v1 为绿色便携版（解压即用，不签名）。首次运行可能看到 Windows SmartScreen 警告，点「仍要运行」即可。

## 数据位置

- 设置与每日统计写入 `%LOCALAPPDATA%\rest-reminder/`（与 exe 位置无关）。
- 删除该目录即可清空全部历史数据。
